<objective>
Migrate download_engine to emit TelemetryEvents instead of directly updating SessionState::performance_metrics.

Purpose: Decouple telemetry emission from metric storage, enabling clean separation between event producers and metric aggregation (done by TelemetryCollector in Phase 2).
Output: download_engine.cpp modified to emit events via TelemetrySession, SessionState extended with TelemetrySession member.
</objective>
